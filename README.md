# ncc1701.at

Startseite der Domain ncc1701.at – "Unbekannte Welten".

- Eine einzige Datei: `index.html` (Warp-Sternenfeld, Logbuch mit Sternzeit, wechselnde Sprüche)
- Vier Themes: Nebula, Eisnebel, Roter Riese, Polarlicht (Punkte unten oder Tasten 1-4, wird im Browser gemerkt)
- Ruhemodus: Panel aus, Vollbild, langsam treibende Nebel (Button oder Taste R, Esc/Klick beendet)
- Klick / Leertaste: Warp-Sprung
- Keine externen Fonts, Skripte oder Bilder
- Gehostet über GitHub Pages
