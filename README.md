# ncc1701.at

Startseite der Domain ncc1701.at – "Unbekannte Welten".

- `index.html`: Warp-Sternenfeld, Logbuch mit Sternzeit, wechselnde Sprüche
- Vier Themes: Nebula, Eisnebel, Roter Riese, Polarlicht (Punkte unten oder Tasten 1-4, wird im Browser gemerkt)
- Ruhemodus: Panel aus, Vollbild, langsam treibende Nebel (Button oder Taste R, Esc/Klick beendet)
- Klick / Leertaste: Warp-Sprung
- Play-Saturn-Knopf -> `/saturn/` (Godot-Web-Build)
- Zähler über GoatCounter (Konto `ncc1701at`, ohne Cookies): Seitenaufrufe `/` und Ereignis `saturn-start`
- `datenschutz.html`: Datenschutzhinweise
- Keine externen Fonts oder Bilder; einziges externes Skript ist GoatCounter
- Gehostet über GitHub Pages
